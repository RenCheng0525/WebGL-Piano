# WebGL Piano

Live Demo: [https://rencheng0525.github.io/WebGL-Piano/](https://rencheng0525.github.io/WebGL-Piano/)

Generated by Claude with prompts only, no manual code editing.

## Overview

A browser-based 3D piano that plays MIDI files with synchronized falling-note visuals. It uses Three.js for rendering, Tone.js for audio, and @tonejs/midi for parsing. You can also play it yourself with a mouse, touch screen, computer keyboard, or a real MIDI keyboard.

The whole app is a single self-contained HTML file. The piano samples are embedded in the file, so it works without a separate audio server.

## Features

### MIDI playback

- **Reliable MIDI parsing**: Uses @tonejs/midi, which handles tempo changes, running status, SysEx, long meta events, and Format 0 and Format 1 files.
- **Sustain pedal support**: CC64 is applied, so notes ring until the pedal is released. Re-striking the same note cuts the previous one, as on a real piano.
- **Accurate timing**: Notes are scheduled with `Tone.Transport` and `Tone.Part` instead of `requestAnimationFrame`. Playback stays in time even when the tab is in the background.
- **Drum tracks skipped**: Channel 10 percussion is ignored rather than played on the piano.
- **Track names decoded**: Non-UTF-8 track names (Big5, GBK, Shift_JIS) are decoded correctly.

### Visuals

- **Falling notes**: A Synthesia-style waterfall shows upcoming notes, colored by track. It is drawn with a single `InstancedMesh` for performance.
- **Full 88-key keyboard**: A0 to C8 with correct white and black key layout.
- **Key animation**: Keys sink according to velocity and light up in their track’s color.
- **Light and dark themes**: The interface and scene follow the system color scheme.

### Audio

- **30 Salamander Grand Piano samples**: One sample every minor third, for much less pitch-shifting distortion than a 4-sample set.
- **Velocity-sensitive dynamics**: MIDI velocity controls loudness.
- **Reverb and limiter**: Light room reverb, with a limiter to prevent clipping in dense passages.

### Controls

- Play, pause, and stop.
- A progress bar you can click or drag to seek. Arrow keys skip 5 seconds when it is focused.
- Playback speed from 0.5× to 2×.
- Volume control.
- A track panel for muting individual tracks.
- Drag-and-drop file loading.
- A built-in demo: the first 19 bars of Bach’s Prelude in C major, BWV 846.

### Playing live

| Input | How |
| --- | --- |
| Mouse or touch | Click or tap keys. Drag across keys for a glissando. Multi-touch is supported. |
| Computer keyboard | `A W S E D F T G Y H U J K` play one octave starting at C. `O L P ;` continue upward. `Z` and `X` shift the octave. `Space` plays or pauses. |
| MIDI keyboard | Click “連接 MIDI 鍵盤” to connect through Web MIDI. The sustain pedal works too. |
| Camera | Drag to orbit, scroll or pinch to zoom, right-drag or two-finger drag to pan. “重設視角” resets the view. |

## Tech stack

- [Three.js](https://threejs.org/) r128 with OrbitControls
- [Tone.js](https://tonejs.github.io/) 14.8.49
- [@tonejs/midi](https://github.com/Tonejs/Midi) 2.0.28

## Browser support

- Recent versions of Chrome, Edge, Firefox, and Safari with WebGL.
- Web MIDI input works in Chrome and Edge. Firefox and Safari do not support it.
- On phones, the camera frames the middle of the keyboard. Pan with two fingers to reach the rest.
